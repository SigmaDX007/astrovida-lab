# Decisões do AstroVida

- Repositório independente SigmaDX007/astrovida-lab, branch main, histórico próprio e sem código comercial.
- Python + Streamlit para laboratório científico local; Node/npm, MCP e LLM não são exigidos.
- NASA TAP e astroquery.mast para consulta a fontes oficiais públicas.
- SQLite e arquivos FITS locais, ignorados no Git; relatórios Markdown exportáveis.
- Estatística de contraste é exploratória e não identifica moléculas ou biologia.
- Limite de download, timeouts e nenhuma API paga por padrão.
